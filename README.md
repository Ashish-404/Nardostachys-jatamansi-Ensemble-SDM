# Nardostachys-jatamansi-Ensemble-SDM
Ensemble (Maxent + GLM + Random Forest) species distribution model projecting current and future habitat suitability for the Critically Endangered Himalayan herb Nardostachys jatamansi under SSP4.5/SSP8.5 climate scenarios, with spatial cross-validation, VIF-based collinearity correction, and bootstrap uncertainty.
